# How to Import to Anki

Importing an Anki Deck Package is easy.

First - you'll need to download Anki. [Here's the link](https://apps.ankiweb.net/)

![Anki Website](/media/resources/network+/How1.jpg)

After you've downloaded and installed Anki, you'll want to navigate to `File > Import` - then select the .apkg file

![Anki File > Import](/media/resources/network+/how2.png)

![Selecting .apgk file](/media/resources/network+/how3.jpg)

Then simply click "Import"

![Import](/media/resources/network+/how4.jpg)
